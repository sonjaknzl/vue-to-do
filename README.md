# vue-to-do

A simple Vue app for a To-Do List.

This project was built by following [this tutorial](https://www.youtube.com/watch?v=5oKpoqmUj64&t=107s).

## How to run

Clone the project, open VSCode and run:

```sh
npm install
```

```sh
npm run dev
```
